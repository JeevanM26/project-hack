Complete Step-by-Step Guide for HP HyperX (i7 14th Gen + RTX 5060 + 24GB RAM)

        

          

            
1. Best Gemma 4 Setup for Your RTX 5060 + 24GB RAM

            

              Your laptop has an NVIDIA RTX 5060 (8GB GDDR7 VRAM) + 24GB System RAM + i7-14th Gen. Run gemma-4-12B-it (Unified Multimodal with native Screen UI Pointing) locally via Ollama with GPU offload:

              ollama run gemma4:12b
              Or for ultra-fast 60+ tok/sec local GUI control totally inside GPU VRAM, run ollama run gemma4:e4b.
            

          


          

            
2. Physical Mouse & GUI Automation (`PyAutoGUI`)

            

              backend/gui_computer_agent.py captures your real screen via PIL.ImageGrab, asks Gemma 4 Vision for normalized [0..1000] coordinates, and glides your physical mouse cursor smoothly with pyautogui.moveTo(x, y, duration=0.75, tween=pyautogui.easeInOutQuad).
            

          


          

            
3. Launch Full-Stack Server on Your Laptop

            
unzip jarvis_gemma4_sarvam_fullstack.zip -d jarvis_mark85
cd jarvis_mark85
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export SARVAM_API_KEY="your_sarvam_key"
export JARVIS_GEMMA_MODEL="gemma-4-12b-it"
cd backend && uvicorn main:app --reload --port 8000

          


          

            
4. Optional QLoRA GUI Fine-Tuning on Your RTX 5060
